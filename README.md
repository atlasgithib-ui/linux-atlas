# 🐧 Linux Atlas Ultra

Linux Atlas Ultra is a small, non-commercial and unofficial personal project — an offline encyclopedia and guide to the world of Linux.

It is designed to help people explore Linux systems, compare them, understand their differences, and find systems that may fit their own needs, hardware, experience and use cases.

> 🇷🇺 **Не ищи «лучший Linux». Найди Linux, который подходит именно тебе.**
>
> 🇬🇧 **Don't look for the “best” Linux. Find the Linux that fits you.**

This is the main idea behind Linux Atlas.

# 🇬🇧 English

## 📚 What is it?

Linux Atlas Ultra is a portable offline encyclopedia about Linux, created as a personal project.

The Atlas contains **215 Linux systems and Linux-related projects**. Entries include information about:

- project philosophy and approach;
- learning difficulty;
- desktop environments and window managers;
- architectures and hardware;
- use cases;
- common commands;
- installation and configuration;
- PCs and ARM devices;
- mobile scenarios;
- troubleshooting and common issues;
- additional material and extended guides.

The information is available in **English and Russian**.

## 💾 Portable and offline

Atlas is distributed as **a single standalone HTML file**.

No separate application or server is required. The file can be stored on a computer, phone, USB drive or another local device and opened in a modern web browser.

The Atlas itself **does not require an Internet connection to work**.

The interface, styles, JavaScript, database and encyclopedia content are contained inside the HTML file.

## 🔎 What's included?

- **215 systems** in the catalog.
- Search and filtering.
- Fuzzy search and closest-match suggestions.
- System comparison.
- User profiles based on Linux experience.
- System difficulty levels.
- Extended offline guides.
- Information about commands, installation, hardware, ARM and mobile scenarios.
- Russian / English interface.
- Responsive desktop and mobile interface.
- Local features and settings that do not require an Internet connection.

## 🖥️ Where can it run?

- Windows;
- Linux;
- macOS;

# 🐧 Project Philosophy

Linux is a huge ecosystem, and there is no single distribution that is right for everyone.

Some people want a simple desktop for everyday work.  
Some need a server.  
Some prefer a minimal system.  
Some enjoy configuring almost everything themselves.  
Others are simply trying Linux for the first time.

That's why the idea behind Atlas is simple:

> 🇷🇺 **Не ищи «лучший Linux». Найди Linux, который подходит именно тебе.**
>
> 🇬🇧 **Don't look for the “best” Linux. Find the Linux that fits you.**

Linux Atlas is not meant to decide for the user which Linux they should use. It is meant to help them explore, compare and understand the choices for themselves.
