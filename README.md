# 🐧 Linux Atlas v6

**Linux Atlas v6** — небольшой, некоммерческий и неофициальный личный проект: портативная офлайн-энциклопедия, справочник и навигатор по миру Linux.

> 🇷🇺 **Не ищи «лучший Linux». Найди Linux, который подходит именно тебе.**
>
> 🇬🇧 **Don't look for the “best” Linux. Find the Linux that fits you.**

Atlas создан для того, чтобы спокойно изучать Linux, сравнивать разные системы, понимать их особенности и находить варианты, которые могут подходить под конкретное оборудование, опыт и задачи пользователя.
