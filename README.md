# 🐧 Linux Atlas v6

Linux Atlas — удобный офлайн-каталог для изучения и сравнения Linux-систем.

Проект помогает быстро разобраться в разных дистрибутивах и выбрать систему под своё оборудование, задачи и предпочтения.

> 🇷🇺 Не ищи «лучший Linux». Найди Linux, который подходит именно тебе.

## ✨ Возможности

Linux Atlas объединяет информацию о 215 Linux-системах и проектах в одном удобном интерфейсе.

### 🔎 Поиск
Быстрый поиск по каталогу помогает находить нужную систему по названию и связанным параметрам.

### 🧩 Фильтрация
Системы можно рассматривать по основным пользовательским характеристикам:
- 🏠 Повседневность
- 🪶 Легковесность
- 🎨 Визуал
- 🙂 Удобство

### ⚖️ Сравнение
Можно выбрать Linux-системы и сравнить их основные характеристики в одном месте.

В сравнении могут отображаться:
- RAM
- накопитель
- CPU
- GPU
- архитектура
- системные требования
- пользовательские характеристики
- другие доступные сведения

### 💻 Для ПК и 📱 телефона
Интерфейс адаптирован для разных размеров экрана.

Linux Atlas можно использовать на компьютере, ноутбуке, планшете и смартфоне.

### 🌐 Русский и English
Интерфейс поддерживает русский и английский языки. Язык можно переключать непосредственно в интерфейсе.

## 📦 Файлы проекта

Основные файлы:

### Вариант 1 — открыть файл напрямую

Скачайте `Linux-Atlas-v6.html` и откройте его в современном браузере.

### Вариант 2 — через терминал

```bash

cd linux-atlas

```

Затем откройте в браузере:

`http://localhost:8000`

## 🐧 Что такое Linux Atlas?

Linux Atlas — справочный каталог для людей, которые хотят разобраться в мире Linux.

Здесь можно:
- изучать разные Linux-системы;
- сравнивать их характеристики;
- искать варианты для своего компьютера;
- смотреть системные требования;

1. Откройте Linux Atlas.

## 🖥️ Системные требования

Linux Atlas является браузерным HTML-проектом.

Для работы требуется:
- современный веб-браузер;
- компьютер, планшет или смартфон;
- включённый JavaScript.

Linux Atlas не устанавливает операционную систему и не изменяет настройки компьютера.

## 🔒 Офлайн-использование

Linux Atlas построен как самостоятельный HTML-проект. После получения файла каталог можно использовать локально.

Доступность внешних ресурсов, если они используются конкретной функцией или материалом, может зависеть от подключения к Интернету.

## 📱 Мобильное использование

Linux Atlas подходит для смартфонов и планшетов. Интерфейс рассчитан на сенсорное управление и небольшую ширину экрана.

Linux Atlas не определяет одну универсальную систему для всех.

У разных пользователей разные компьютеры, задачи, требования, привычки и предпочтения. Каталог помогает самостоятельно сравнить варианты и найти подходящую систему.

## 🐧 What is Linux Atlas?

Linux Atlas is a reference catalog for people who want to explore the Linux ecosystem.

You can:
- explore different Linux systems;
- compare their characteristics;
- look for options for your computer;
- check system requirements;
- evaluate ease of use;
- find lightweight systems for older hardware;
- explore visually focused systems;
- find options for everyday use.

## 💡 How to Use It

1. Open Linux Atlas.
2. Choose a language: 🇷🇺 Russian or 🇬🇧 English.
3. Use search or filters.
4. Open detailed information about a system.
5. Select systems for comparison.

## 🖥️ System Requirements

Linux Atlas is a browser-based HTML project.

You need:
- a modern web browser;
- a computer, tablet, or smartphone;
- JavaScript enabled.

Linux Atlas does not install an operating system or change your computer settings.

## 🔒 Offline Use

Linux Atlas is designed as a self-contained HTML project. After obtaining the file, the catalog can be used locally.

Availability of external resources, if used by a particular function or piece of content, may depend on an Internet connection.

## 📱 Mobile Use

Linux Atlas is suitable for smartphones and tablets. The interface is designed for touch control and smaller screens.

## 🎯 The Main Idea

Linux Atlas does not define one universal system for everyone.

Users have different computers, tasks, requirements, habits, and preferences. The catalog helps users compare the available options and find a system that fits their needs.

> Linux Atlas — find the Linux that fits you.

- what the system is;

- how lightweight it is;
