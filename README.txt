# Linux Atlas v6
# Понятная инструкция для пользователя
#
# 🇷🇺 РУССКИЙ ЯЗЫК

Добро пожаловать в Linux Atlas v6.

Linux Atlas — это личная, неофициальная и некоммерческая офлайн-энциклопедия для изучения 215 Linux-систем и связанных проектов.

Главная задача проекта — сделать знакомство с Linux простым, понятным и удобным. Здесь можно искать системы, использовать фильтры, открывать подробную информацию, сравнивать варианты и ориентироваться на собственные задачи.

--------------------------------------------------
1. ЧТО НАХОДИТСЯ В ПРОЕКТЕ
--------------------------------------------------

В проекте используются основные файлы:

index.html
Linux-Atlas-v6.html
README.txt

README.txt — это данная инструкция.

index.html — удобная точка входа в проект.

Linux-Atlas-v6.html — основной файл каталога Linux Atlas v6.

Главный каталог находится внутри HTML-файла, поэтому для обычного использования не требуется устанавливать отдельную программу.

--------------------------------------------------
2. КАК БЫСТРО НАЧАТЬ
--------------------------------------------------

Самый простой способ:

1. Получите файлы проекта.
2. Откройте index.html.
3. Перейдите в Linux Atlas.
4. Выберите русский или английский язык.
5. Используйте поиск или фильтры.
6. Откройте интересующую систему.
7. При необходимости добавьте системы в сравнение.

Если вы уже получили основной файл Linux-Atlas-v6.html, его также можно открыть непосредственно в современном браузере.

--------------------------------------------------
3. КАК ПОЛЬЗОВАТЬСЯ ПОИСКОМ
--------------------------------------------------

Поиск помогает быстро найти нужную систему среди каталога.

Введите в поле поиска название или часть названия.

После этого каталог покажет соответствующие результаты.

Поиск особенно удобен, когда вы уже знаете название системы и не хотите просматривать весь каталог вручную.

--------------------------------------------------
4. КАК ПОЛЬЗОВАТЬСЯ ФИЛЬТРАМИ
--------------------------------------------------

Фильтры помогают сузить список систем и найти варианты, которые больше подходят под ваши задачи.

В Linux Atlas используются пользовательские направления:

Повседневность
Подходит для оценки систем с точки зрения обычного ежедневного использования.

Легковесность
Помогает искать варианты, ориентированные на более слабое или старое оборудование.

Визуал
Помогает обратить внимание на внешний вид и визуальную часть системы.

Удобство
Помогает оценить системы с точки зрения повседневного взаимодействия и удобства работы.

Фильтры предназначены как инструмент навигации. Они не означают, что одна система универсально лучше другой.

--------------------------------------------------
5. ПРОФИЛЬ ПОЛЬЗОВАТЕЛЯ
--------------------------------------------------

Профили помогают начать поиск с вашей ситуации.

Если вы обычный пользователь и не хотите разбираться в технических деталях сразу, начните с соответствующего профиля.

После выбора профиля можно перейти к дополнительным направлениям:

- Повседневность
- Легковесность
- Визуал
- Удобство

Так проще постепенно сузить выбор без необходимости сразу изучать все технические характеристики.

--------------------------------------------------
6. ПОДРОБНАЯ ИНФОРМАЦИЯ О СИСТЕМЕ
--------------------------------------------------

Открыв карточку или страницу системы, вы можете посмотреть доступную информацию о ней.

В зависимости от конкретного проекта могут отображаться:

- системные требования;
- RAM;
- накопитель;
- CPU;
- GPU;
- архитектура;
- особенности использования;
- другие технические и пользовательские сведения.

Обращайте внимание на конкретные требования именно той версии системы, которую вы собираетесь устанавливать.

Если какое-либо значение не указано, не следует автоматически считать, что требования отсутствуют. Для окончательной проверки всегда полезно посмотреть официальную документацию соответствующего проекта.

--------------------------------------------------
7. СРАВНЕНИЕ СИСТЕМ
--------------------------------------------------

В Linux Atlas можно выбрать системы для сравнения.

Сравнение предназначено для того, чтобы быстрее увидеть различия между выбранными вариантами.

В зависимости от доступных данных можно сопоставлять:

- RAM;
- накопитель;
- CPU;
- GPU;
- архитектуру;
- системные требования;
- пользовательские параметры;
- другие доступные характеристики.

На компьютере сравнение удобно использовать на широком экране.

На телефоне сравнение адаптировано под небольшой экран.

Если вы хотите использовать локальный сервер, например для более предсказуемого поведения браузера, можно запустить простой сервер Python:

python3 -m http.server 8000

После запуска откройте в браузере:

Чтобы остановить сервер, вернитесь в терминал и нажмите:

# 🇬🇧 ENGLISH
# Simple and Friendly User Guide
==================================================

Welcome to Linux Atlas v6.

Linux Atlas is a personal, unofficial and non-commercial offline encyclopedia for exploring 215 Linux systems and related projects.

The main goal is to make exploring Linux simple, clear and convenient. You can search systems, use filters, open detailed information, compare options and navigate according to your own needs.

--------------------------------------------------
1. WHAT IS INCLUDED
--------------------------------------------------

The project uses these main files:

index.html
Linux-Atlas-v6.html
README.txt

README.txt is this guide.

index.html is a convenient project entry point.

Linux-Atlas-v6.html is the main Linux Atlas v6 catalog.

The main catalog is contained in the HTML project, so normal use does not require installing a separate application.

--------------------------------------------------
2. HOW TO START
--------------------------------------------------

The easiest way:

1. Get the project files.
2. Open index.html.
3. Enter Linux Atlas.
4. Choose Russian or English.
5. Use search or filters.
6. Open a system you are interested in.
7. Add systems to comparison when needed.

If you already have Linux-Atlas-v6.html, you can also open it directly in a modern web browser.

--------------------------------------------------
3. USING SEARCH
--------------------------------------------------

Search helps you quickly find a system in the catalog.

Type a system name or part of its name into the search field.

The catalog will show matching results.

Search is especially useful when you already know what system you want to find.

--------------------------------------------------
4. USING FILTERS
--------------------------------------------------

Filters help narrow the catalog and find systems that better match your needs.

Linux Atlas uses four user-oriented directions:

Everyday
Useful for exploring systems from the point of view of normal daily use.

Lightweight
Useful for finding systems aimed at older or less powerful hardware.

Visual
Useful for exploring systems where visual appearance is an important part of the experience.

Convenience
Useful for considering systems from the point of view of everyday interaction and ease of use.

Filters are navigation tools. They do not mean that one system is universally better than another.

--------------------------------------------------
5. USER PROFILES
--------------------------------------------------

Profiles help you start from your situation.

If you are a regular user and do not want to deal with technical details immediately, start with the relevant profile.

After selecting a profile, you can continue with additional directions:

- Everyday
- Lightweight
- Visual
- Convenience

This makes it easier to narrow the catalog gradually instead of studying every technical detail at once.

--------------------------------------------------
6. DETAILED SYSTEM INFORMATION
--------------------------------------------------

When you open a system card or page, you can view the available information about it.

Depending on the project, this may include:

- system requirements;
- RAM;
- storage;
- CPU;
- GPU;
- architecture;
- usage characteristics;
- other technical and user-oriented information.

Pay attention to the exact version of the system you plan to install.

If a value is not listed, do not automatically assume that there is no requirement. For final verification, it is recommended to check the official documentation of the relevant project.

--------------------------------------------------
7. COMPARING SYSTEMS
--------------------------------------------------

Linux Atlas allows you to select systems for comparison.

Comparison is designed to make differences between selected options easier to understand.

Depending on the available data, you may compare:

- RAM;
- storage;
- CPU;
- GPU;
- architecture;
- system requirements;
- user-oriented parameters;
- other available characteristics.

Comparison is convenient on a desktop or laptop screen.

On a phone, the comparison interface is adapted to a smaller display.

--------------------------------------------------
8. RUSSIAN AND ENGLISH
--------------------------------------------------

Linux Atlas supports two languages:

🇷🇺 Russian
🇬🇧 English

You can switch the language directly in the interface.

On a computer, the language switch is convenient to use with a mouse.

On a phone, the interface is designed for touch interaction.

--------------------------------------------------
9. DESKTOP USE
--------------------------------------------------

Linux Atlas can be used on:

- desktop computers;
- laptops.

A larger screen makes it easier to work with search, filters, system cards and comparison at the same time.

A modern web browser is normally sufficient.

10. PHONE AND TABLET USE
--------------------------------------------------

On a phone:

1. Open the project in your browser.

3. Use search.
4. Open filters.
5. Browse system cards.
6. Use comparison when needed.

For a small screen, portrait orientation is usually convenient. For wider comparison, you can rotate the device to landscape mode.

For normal local use:

2. Save them in a convenient folder.
3. Open index.html
   or directly open Linux-Atlas-v6.html.

Important:

If a specific function or external material depends on an external Internet resource, its availability may depend on your Internet connection.

--------------------------------------------------
14. RUNNING A LOCAL SERVER
--------------------------------------------------

Opening the HTML file directly is normally enough.

If you prefer to use a local server, for example for more predictable browser behavior, you can use the simple Python server:

python3 -m http.server 8000

Then open:

http://localhost:8000

To stop the server, return to the terminal and press:

Ctrl+C

--------------------------------------------------

--------------------------------------------------

Try these steps:

2. Reload the page.

5. Open index.html again.

If only one specific function has a problem, check whether it depends on an external resource or an Internet connection.
